# e-ink панель (Raspberry Pi Zero 2 W)

Настольная панель на e-ink экране. По кругу показывает экраны:

1. **Погода** — текущая температура, ощущается, осадки, мин/макс (Open-Meteo, без ключа).
2. **Серверы** — доступность твоих сервисов (HTTP-проверка).
3. **Сегодня** — события на сегодня из Remember_bot (твой бот напоминаний).
4. **Спутники** — ближайшие пролёты (МКС и любые другие по NORAD ID) над городом, по TLE.

## Зависимости

- Стандартная библиотека Python 3.9+.
- `skyfield` — только для предсказания пролётов спутников (TLE-расчёт).

```bash
pip install -r requirements.txt
```

## Настройка

Всё в `config.py`: город/координаты, список серверов, спутники, ротация экранов.

Токен планировщика задай переменной окружения (не коммить в репозиторий):

```bash
export PLANNER_API_TOKEN=...
```

## Запуск (проверка логики, без экрана)

```bash
python main.py
```

Выведет данные экранов в консоль и будет крутить их по кругу.

## Статус

Пока реализована только **логика**: сбор данных + ротация. Отрисовка на e-ink
добавится отдельным `EinkRenderer`, когда будет известна модель экрана — он
принимает те же dict-данные, что и консольная заглушка.
